Overview

What is Zenith?

Zenith is an automated trading bot that runs inside MetaTrader 5 and trades on your behalf 24/7. It uses Smart Money Concepts (the same methods used by institutional traders) to find high-probability entries on EURUSD, NAS100, and Gold (XAUUSD).

MT5 Expert Advisor

The EA runs directly inside MetaTrader 5. You just attach it to a chart — it handles everything else automatically.

Built-in Risk Control

Automatic stop-loss on every trade. Daily drawdown kill-switch. Max 3 trades per day per symbol.

Live Dashboard

Watch every trade in real-time. Equity curve, win rate, P&L — all updated live in your browser.

You do not need to know how to code. You just download the EA file, put it in the right folder, and click a few buttons in MetaTrader 5.
Step 1

Install MetaTrader 5

MetaTrader 5 is a free trading platform. You need it installed on your Windows PC or laptop — the Zenith EA runs inside it.

1 Download MT5

Go to metatrader5.com and click "Download MetaTrader 5". Run the installer — it takes about 2 minutes.

2 Open MT5 and Log In

After install, MT5 opens automatically. You'll see a login window.

  • Enter your broker login, password, and server (from your broker's welcome email)
  • Click Login — you should see your account balance appear in the top bar
  • If you see charts loading, you're in ✓
MT5 only works on Windows. Mac users need to use a Windows VPS (virtual server) or Parallels/Boot Camp.
Step 2

Choose a Broker

You need a broker that supports MT5 and offers the instruments Zenith trades: EURUSD, NAS100, XAUUSD.

Recommended Brokers

IC Markets, Pepperstone, FP Markets, Exness — all offer MT5, low spreads, and all 3 required symbols.

Start with a Demo Account

Every broker lets you open a free demo account with virtual money. Test Zenith there first — no risk.

Make sure EURUSD, NAS100 (or US100), and XAUUSD (or Gold) are visible in your broker's Market Watch panel inside MT5.
Step 3

Download the Zenith EA

The EA (Expert Advisor) is the file that actually runs inside MetaTrader 5 and executes trades. Download it directly from the Zenith dashboard.

1 Log into your Zenith account

Go to your dashboard → click "Download EA" in the top right corner.

2 What's in the download?

You'll receive a ZIP file containing:

  • ZenithEA.mq5 — the EA source file (goes into MT5)
  • EA_Config_Template.set — pre-filled settings file
Zenith is open-source — you can see exactly what the bot does. There are no hidden fees or subscriptions inside the EA itself.
Step 4

Install & Compile the EA in MT5

The EA file needs to be placed in the correct MT5 folder and compiled once. This takes about 2 minutes.

1 Open the MT5 Data Folder

In MetaTrader 5, click the top menu: File → Open Data Folder

Navigate to: MQL5 → Experts — this is where Expert Advisors live.

2 Copy the EA File

Copy ZenithEA.mq5 from the ZIP into the Experts folder. Leave the window open.

3 Compile in MetaEditor

  • Back in MT5, press F4 (or click Tools → MetaEditor) to open MetaEditor
  • In the left panel, find Experts → ZenithEA.mq5 and double-click it
  • Press F7 to compile — wait for the green "0 errors" message at the bottom
  • Close MetaEditor and go back to MT5
If you see "0 errors, 0 warnings" in the MetaEditor log — the EA is ready to use.
Step 5

Attach the EA to a Chart

You only need to attach the EA to one chart. From that single chart it can trade all 3 symbols automatically.

1 Open a Chart

In MT5, right-click in the Market Watch panel on EURUSD → Chart Window. Make sure the chart is set to M15 timeframe (15-minute candles).

2 Drag the EA onto the Chart

  • In the Navigator panel (left side), expand Expert Advisors
  • Find ZenithEA and drag it onto the chart
  • A settings dialog will appear — see the next step before clicking OK

3 Enable "Allow Automated Trading"

In the dialog, go to the "Common" tab and make sure "Allow automated trading" is ticked. Also enable it in the top MT5 toolbar (the green "AutoTrading" button).

If the AutoTrading button in the MT5 toolbar is red, click it to turn it green — otherwise the EA will not execute any trades.

Step 7

Demo Mode vs Live Trading

Always start with Demo Mode. It simulates real trades without using any real money — perfect for testing that everything works.

Demo Mode (Recommended first)

  • Set DemoMode = true
  • Leave LiveTrading = false
  • EA simulates trades, no real orders placed
  • All signals show on the dashboard

Live Trading (Real money)

  • Set DemoMode = false
  • Set LiveTrading = true
  • Real orders are sent to your broker
  • Only switch after successful demo period
Run Demo Mode for at least 1–2 weeks before switching to live. Watch the dashboard to verify the signals make sense for your market conditions.

FAQ

Frequently Asked Questions

Do I need to leave my computer on all day?

Yes — MT5 needs to be running for the EA to work. If you want it truly 24/7, use a Windows VPS (Virtual Private Server). Many brokers offer free VPS hosting for active accounts.

Will the EA open trades while I'm asleep?

Yes — that's the whole point. It monitors the market automatically and only enters trades that meet all its criteria. You'll get a Telegram notification when something happens.

Can I use it on a Demo account first?

Absolutely — and we strongly recommend it. Set DemoMode = true in the EA settings. Demo mode simulates trades with fake money so you can see exactly how the bot behaves before risking anything real.

What if I only want to trade one symbol?

Set TradeChartSymbol = true and leave ExtraSymbol1, ExtraSymbol2, ExtraSymbol3 empty. The EA will only trade whichever symbol the chart is on.

How much money do I need to start?

The bot works with any account size. We recommend starting with at least $500–$1000 on a live account so that position sizing is meaningful. With a demo account, you can start with any virtual balance your broker provides.

What is the recommended risk per trade?

The default is 1% per trade. This means on a $1,000 account, the maximum loss per trade is $10. You can adjust this in the EA settings under Risk Management, but never go above 2–3% if you're new to automated trading.

Help

Troubleshooting

EA shows a smiley face but no trades appear

This is normal — the EA only trades during its configured session windows. Check the monitoring table above to see if the current UTC time falls inside a trading session. Also check that DemoMode = true or LiveTrading = true.

The AutoTrading button is red / greyed out

Click the AutoTrading button in the MT5 toolbar to turn it green. Also right-click the chart → Expert Advisors → Make sure "Allow automated trading" is ticked in the EA properties.

Dashboard not showing live data from the EA

Check that your DashboardURL and DashboardAPIKey in the EA settings are correct. Also go to MT5 → Tools → Options → Expert Advisors → Add your dashboard URL to the allowed URLs list (for WebRequest).

Compilation error when pressing F7

Make sure you downloaded the latest version of the EA from the dashboard. Older versions may be incompatible with your MT5 build. Try deleting the old file and re-downloading.

Can't find NAS100 or XAUUSD in Market Watch

Right-click inside Market Watch → Show All, or search for the symbol (some brokers name it US100, NASDAQ, or GOLD). If it's still missing, contact your broker — not all brokers offer all instruments.
